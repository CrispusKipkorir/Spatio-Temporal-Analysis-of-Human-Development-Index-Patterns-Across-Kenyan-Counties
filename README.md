# Spatio-Temporal Analysis of Human Development Index Patterns Across Kenyan Counties

An interactive geospatial platform for exploring **human development, poverty, and multidimensional deprivation across Kenya's 47 counties**.

The project combines county-level socioeconomic indicators with interactive web mapping to examine **spatial disparities and temporal patterns in human development across Kenya**.

## Project Overview

Human development outcomes vary substantially across Kenya, with differences in income, education, health, and multidimensional poverty between counties.

This project provides an interactive interface for exploring these geographic patterns and comparing development indicators at county level.

## Key Features

- **Interactive choropleth mapping** of six human development and poverty indicators
- **County-level spatial comparison** across Kenya's 47 counties
- **Temporal exploration** of available historical and national trend data
- **County selection and side-by-side comparison**
- **Interactive map legends and indicator information**
- **Map export** to PNG, JPG, and PDF
- **Responsive interface** for desktop and mobile screens
- Detailed explanations of indicators and their data sources

## Indicators

The platform includes indicators such as:

- Human Development Index (HDI)
- Poverty Headcount
- Multidimensional Poverty Index (MPI)
- Other socioeconomic and development indicators included in the underlying datasets

## Data Sources

The analysis draws on publicly available development and socioeconomic information from:

- **Kenya National Bureau of Statistics (KNBS)**
- **United Nations Development Programme (UNDP)**
- **Oxford Poverty and Human Development Initiative (OPHI)**

National-level historical and trend information was referenced from sources including UNDP Human Development Reports and KNBS Economic Surveys.

## Methodology

The project follows a geospatial visualization workflow:

1. Compile and harmonize county-level development indicators
2. Link socioeconomic indicators to Kenya's county boundaries
3. Classify indicators for thematic mapping
4. Visualize spatial patterns using interactive choropleth maps
5. Enable county-level comparison and exploration
6. Provide contextual information to support interpretation of the indicators

## Technology Stack

| Technology | Application |
